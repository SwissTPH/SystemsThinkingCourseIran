# Applied Systems Thinking Course

This repository contains the report of the **Applied Systems Thinking for Health Systems Managers and Researchers** virtual course, held in October 2021.

The course was coordinated by **Swiss TPH** in collaboration with **Tehran University of Medical Sciences (TUMS)**, with contributions from collaborators in Pakistan. It aimed to strengthen the application of systems-thinking approaches in health systems research and practice.

The multi-day programme combined lectures, facilitated group work and panel discussions, covering topics including **causal loop diagrams, health information systems, and process mapping and modelling**.
